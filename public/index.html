Jira Dependency Map

This is the browser frontend for the same dependency-map engine used by the CLI. Pasted data is converted with this repository's own remapper.mjs and toDot.mjs modules.

Copy rows from Excel, Google Sheets, or a Jira CSV export. Live Jira credentials are deliberately not accepted by this public demo; authenticated Jira querying remains a CLI workflow.

Spreadsheet data

Friendly columns: Key, Summary, Status, Story Points, Group, Blocks, Blocked By. Common Jira export aliases are also accepted.
